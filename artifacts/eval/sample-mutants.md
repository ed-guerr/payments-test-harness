# Fault kill matrix

Generated by `npm run eval:mutants` on 2026-11-04 — every committed suite (excluding the intentionally red `assertion-failure-demo`) run against a FAULTS=1 backend build, once per fault.

## Faults

Eight one-line faults, compiled only with `make FAULTS=1` (`-DPAY_FAULTS`), selected at runtime with `PAY_FAULT=<name>`. Four are business-logic regressions; four are literal reverts of real bugs found and fixed in this codebase (each revert is the pre-fix behavior, in one place).

| fault | kind | description |
|---|---|---|
| `skip_forward` | business | Authorize approves but never forwards CompletePayment (payment stays open) |
| `settle_wrong_acct` | business | Settle moves the amount into ACCT-002 instead of the reserve |
| `double_settle_ok` | business | the already-settled check is skipped, so a second Settle is not rejected as settled |
| `reverse_noop` | business | ReverseTransfer is acked TR_OK without touching the ledger |
| `skip_balance_check` | real-bug | db_transfer debits with no sufficiency guard — the pre-fix check-then-act race (clamped by the fix's non-negative backstop) |
| `oob_copy` | real-bug | unbounded 16-byte copies of sqlite text columns — the pre-fix out-of-bounds read |
| `no_field_validation` | real-bug | dispatch skips wire-field validation (unterminated strings, out-of-range amounts) |
| `db_error_as_no_entry` | real-bug | a reverse db error is reported as the business status TR_NO_ENTRY instead of ErrorAck |

## Survivors — what actually pins them

A fault surviving every suite is not automatically a gap in the suite: some of these bugs are only observable through inputs or states the committed suites never produce. The table says what pins each survivor in this repo:

| fault | survives all of | pinned by |
|---|---|---|
| `oob_copy` | 7 suites | code review — the overrun stays inside SQLite's own heap block, so the ASan build does not flag it either |
| `no_field_validation` | 7 suites | smoke_test.py malformed-frame checks (the committed suites only send well-formed frames via the codec) |
| `db_error_as_no_entry` | 7 suites | smoke_test.py db-error check (no committed suite forces a db-layer error) |
